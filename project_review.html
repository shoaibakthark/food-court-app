🔒 What is CRITICALLY NEEDED (Security, Database & Backups)
1. Password Hashing (bcrypt / passlib) High Priority Security
Vulnerability: Passwords (admin123, owner123, manager123) are currently stored in plain text in the database. During login, the backend evaluates if user.password != password.
Consequence: Anyone with access to a database backup, dump file, or read permissions can see all passwords instantly.
Remedy: Install passlib[bcrypt], hash passwords before saving, and verify using pwd_context.verify(password, user.password_hash).
2. Cryptographic JWT Authentication & RBAC High Priority Security
Vulnerability: The backend role-based access middleware trusts the client-provided header X-User-Role without verifying a server-signed secret key.
Consequence: Any external client, Postman script, or curl command can send X-User-Role: admin and bypass all manager/owner restrictions.
Remedy: Issue signed JWT tokens on login signed with SECRET_KEY. Verify the token on every protected API call.
3. Remove Passwords from Public Endpoints (GET /auth/roles) Information Leak
The public endpoint /auth/roles explicitly returns {"default_password": "admin123", ...} in its JSON response.
Remedy: Remove default_password from the endpoint response payload.
4. Complete Alembic Migration Synchronization Database Integrity
Alembic migration files stopped at version d19624156c35 on Oct 3. Newer tables (KitchenStaff, KitchenDuty, ExpenseSettlement, SubTeam) were created via dynamic fallback. Deploying on a new database with Alembic alone will fail unless migrations are brought up to date.
Remedy: Run alembic revision --autogenerate -m "sync_full_schema" to capture all current models.
5. Automated Permanent Drive Backup Script Data Protection
While the Google Drive Excel exporter works well for spreadsheets, the actual PostgreSQL database needs daily automated binary dumps (pg_dump) stored directly onto your permanent drive or external storage.
Remedy: Create a lightweight Windows backup_database.bat scheduled via Windows Task Scheduler to back up to your permanent drive automatically.
